# Installation and controls

Use an Analogue Pocket with openFPGA-capable firmware. Check the selected release notes for its tested firmware and Dock status.

1. Quit any running core normally, power down and mount the SD card.
2. Back up existing saves. Extract the release ZIP at the card root, merging its `Cores`, `Platforms` and `Assets` folders. Do not put the ZIP inside another core folder or create a second nested copy of these folders.
3. Eject the card safely, insert it into Pocket and select **Voyage to Oregon** from openFPGA.
4. Choose **New Journey**, follow the introduction and shooting-expertise choice, then buy supplies and review your setup before departing.

## Controls

- **Up/Down:** move between available choices.
- **A:** select the highlighted choice. Follow the on-screen button badge if controls are remapped.
- **Left/Right:** move between Map, Play and History when available; follow each page's interaction.
- **Y:** open Help, including resource/status icons and available controls.
- **Select:** open session Options, including large view and face-button mapping.
- **Start in Options:** reset controls to their defaults.
- **Large view:** hold R with a direction to pan; L returns to the top-left.

Shooting measures response timing. Start when ready and respond to the prompt with the indicated game button; the animated animal is visual feedback rather than a collision target. Opening Options pauses the activity.

## Save and resume

Use the in-game Save/Load screens for one of three slots. Saving stages progress; finish with **normal Pocket menu Quit** so the runtime can write to the SD card. Do not remove the card or force power off immediately after saving. Relaunch the game and choose Load to resume.

An active timed shot must finish before saving. Pocket save states and sleep/resume are unsupported. Keep backups before updating a test build; read release notes for save compatibility.

Classic retains original fatal endings. The party display and map record only deaths those rules establish; unknown companion outcomes are not presented as confirmed deaths. Oxen represent the original purchased team rating, not a count of individually simulated animals.

## Troubleshooting

For a blank/corrupt screen or failure to load, check the release version and extraction layout before replacing files. Report the firmware version, cold boot versus relaunch, a screenshot and exact steps. Do not overwrite unrelated cores or delete saves as a first troubleshooting step.
